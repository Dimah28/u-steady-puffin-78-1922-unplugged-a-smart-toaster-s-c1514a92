One line, under 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch.

`main.py` (stdlib only, deterministic, no network) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` and validates it is a single line of 1–280 characters.
